# Fuel System

A complete fuel system for FiveM with fuel consumption and refueling.

## Features

- Fuel consumption based on vehicle movement
- Refueling system with cost calculation
- Database integration to store fuel levels

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your FiveM resources folder
3. Add `start fuel_system` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Players will automatically lose fuel while driving
- Use the refueling system to add fuel to vehicles

## Configuration

- `Config.FuelPrice`: Price per liter of fuel
- `Config.MaxFuel`: Maximum fuel capacity
- `Config.FuelConsumptionRate`: Fuel consumption rate per second
